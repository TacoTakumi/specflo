Each team is one markdown file in the teams folder of the pool directory: its roles, each a pool and how many of the pool's leases the role takes, and notes for whoever leads it. The files are the source of truth: a save here writes the file an admin edits by hand, and a hand edit shows here on the next read. The roles are filled from the pools the pool file declares, and what fills a pool is an agent definition.
